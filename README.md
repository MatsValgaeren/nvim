This is my personal config for nvim.

1. Install nvim Pre-built archive from https://neovim.io/doc/install/
2. clone this repo in `~/.config/`

## Added Plugins:

- knap: writing LaTeX
- toggleterm: easier switching between terminal
- claude-code integration

## Configured Hotkeys:

Open Claude: CTRL + ,  
Run Python: SPACE + r + t
